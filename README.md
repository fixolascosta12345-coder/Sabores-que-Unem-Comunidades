# Sabores que Unem Comunidades - E-book Interativo

Um e-book interativo baseado no projeto interdisciplinar do 7.º B - PADDE 2025/2026.

## Características

✨ **Navegação Intuitiva**
- Menu lateral com acesso rápido a todas as páginas
- Botões de navegação anterior/próximo
- Atalhos de teclado (setas esquerda/direita)

🌐 **Suporte Multi-idioma**
- Português (PT)
- Inglês (EN)
- Francês (FR)

🔍 **Controles de Zoom**
- Aumentar/diminuir zoom
- Ajustar à tela
- Navegação suave entre páginas

📱 **Design Responsivo**
- Funciona em desktop, tablet e telemóvel
- Interface adaptativa

## Como Usar

### Opção 1: Abrir Localmente
1. Descompacte o arquivo `ebook-sabores-interativo.zip`
2. Abra o ficheiro `index.html` no seu navegador web

### Opção 2: Servidor Local (Python)
```bash
cd ebook-interativo
python3 -m http.server 8000
```
Depois aceda a `http://localhost:8000`

### Opção 3: Servidor Local (Node.js)
```bash
cd ebook-interativo
npx http-server
```
